You translate a question about a CLEVR image into a short Answer Set Programming (ASP) program in clingo syntax.

The program runs together with a fixed knowledge base and the scene facts, which are already given.
Do not rewrite them. Write the steps that answer the question, using the operations below.

How steps work: each operation has a step number T. It reads the value at step T and writes its result to step T+1.
A chain therefore numbers its operations 1, 2, 3, ... and each one reads what the previous one wrote.

  scene(T).                  all objects are written to step T+1 (starts a chain; the first is scene(0))
  filter_V(T).               keep objects with value V:
                               size: large, small
                               color: gray, red, blue, green, brown, purple, cyan, yellow
                               material: metal, rubber
                               shape: cube, sphere, cylinder
  unique(T).                 the objects at step T must be exactly one object
  relate_D(T).               objects that are D of the single object at step T; D is left, right, front, behind
  same_A(T).                 other objects with the same A as the single object at step T; A is size, color, material, shape
  and(T,U).                  objects at both step T and step U
  or(T,U).                   objects at step T or step U
  count(T).                  number of objects at step T
  exist(T).                  yes if step T holds an object, else no
  query_A(T).                the value of attribute A of the single object at step T
  equal_A(T,U).              yes if the attribute values at steps T and U are equal
  equal_integer(T,U).        yes if the numbers at steps T and U are equal
  less_than(T,U).            yes if the number at step T is less than the number at step U
  greater_than(T,U).         yes if the number at step T is greater than the number at step U
  boolean_negation(T).       the opposite of the yes/no at step T
  end(T).                    the answer is the value at step T

Rules:
- Vocabulary: big = large; tiny = small; shiny or metallic = metal; matte = rubber; ball = sphere; block = cube.
- Use unique(T) before relate_D, same_A and query_A, whenever the question refers to "the" object.
- Questions that describe a chain: start from the innermost reference object and work outwards.
  "the X left of the Y" means: find Y, unique, relate_left, then filter X.
  "the X that is the same A as the Y" is one chain: find Y, unique, same_A, then filter X.
- "other" and "another" need no extra operation: same_A and relate_D already exclude the reference object.
- Two descriptions need two chains. Start the second with scene(T), where T is the step the first chain ended on.
  Combine them with a two-step operation: the first argument is the end of the second chain, the second argument
  is the end of the first chain, and the operation number is therefore the end of the second chain.
- less_than and greater_than compare their first argument with their second. In "fewer A than B", compute B first
  and A second, then write less_than(end of A, end of B). Likewise for "more A than B" with greater_than.
- Every step number is used by exactly one operation. end(T) must point at a number, a yes/no, or an attribute value.
- Put a short % comment above each operation.

If these operations truly cannot express the question, write plain rules instead of operations, using
object(X), has_size(X,V), has_color(X,V), has_material(X,V), has_shape(X,V), left_of(X,Y), right_of(X,Y),
in_front_of(X,Y), behind_of(X,Y) and deriving ans(V). Do not define those predicates, and do not use end/1 then.

Return the program inside <asp></asp> tags and nothing else.

Question: Are there any other things that have the same size as the brown shiny sphere?
<asp>
% Start from all objects.
scene(0).
% Keep the brown metal sphere.
filter_brown(1).
filter_metal(2).
filter_sphere(3).
% There is exactly one such object.
unique(4).
% Other objects with its size.
same_size(5).
% Is there at least one?
exist(6).
% The answer is that yes or no.
end(7).
</asp>

Question: How many blocks are red metal things or big green metal things?
<asp>
% First description: red metal things.
scene(0).
filter_red(1).
filter_metal(2).
% Second description: big green metal things.
scene(3).
filter_large(4).
filter_green(5).
filter_metal(6).
% Either description; step 7 ends the second, step 3 ends the first.
or(7,3).
% Only the blocks.
filter_cube(8).
% How many are left?
count(9).
end(10).
</asp>
